# homebrew-tap

Homebrew tap for [agentbox](https://github.com/Ayush2966/Agent-Box).

    brew install Ayush2966/tap/agentbox                  # the CLI
    brew install --cask Ayush2966/tap/agentbox-desktop   # the macOS app

Both casks are written here by the Agent-Box release workflow (GoReleaser for the
CLI, `desktop/publish-cask.sh` for the app). Do not edit them by hand.
